Captain Amany — Portfolio

Files added:
- `Untitled-1.html` — main HTML (rename to `index.html` if you want it as default)
- `styles.css` — site styles
- `script.js` — basic interactivity (nav toggle, smooth scroll, contact form)
 - `assets/images/profile1.jpg` — profile photo 1 (place your uploaded image here)
 - `assets/images/profile2.jpg` — profile photo 2 (place your uploaded image here)

To preview locally:
1. Open `Untitled-1.html` in your browser.
2. Or run a simple local server, e.g. with Python:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/Untitled-1.html`.

To add your real photos, copy the image files you uploaded into `assets/images/` and name them `profile1.jpg` and `profile2.jpg`.

Example (PowerShell):

```powershell
Copy-Item -Path "C:\path\to\your\photo1.jpg" -Destination "assets/images/profile1.jpg"
Copy-Item -Path "C:\path\to\your\photo2.jpg" -Destination "assets/images/profile2.jpg"
```
